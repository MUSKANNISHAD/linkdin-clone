# Professional Networking Platform

A full-stack professional networking platform that enables users to create profiles, connect with professionals, share posts, and interact with their network. The application provides a modern social networking experience with authentication, profile management, and real-time interactions.

---

## ✨ Features

- 🔐 Secure User Authentication (Register/Login)
- 👤 User Profile Creation & Management
- 📝 Create, Edit, and Delete Posts
- ❤️ Like and Comment on Posts
- 🖼️ Upload Profile & Cover Images
- 👥 Connect with Other Users
- 🔍 Search Users
- 📱 Responsive User Interface
- ⚡ Fast and Interactive Experience

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/MUSKANNISHAD/linkdin-clone.git
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
